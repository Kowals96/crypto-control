# Crypto Control

Aplikacja do śledzenia portfela krypto (wersja na telefon / PWA).

Repozytorium zawiera tylko kod – bez żadnych danych finansowych. Dane (pozycje, transakcje, oszczędności, PIN)
są zapisywane wyłącznie w pamięci urządzenia i przenoszone kopią zapasową (Ustawienia → Dane).

Instalacja na iPhonie: otwórz adres strony w Safari → Udostępnij → „Do ekranu początkowego”.
